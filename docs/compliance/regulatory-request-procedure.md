# Регламент обработки запроса уполномоченного органа (FZ-10.6)

1. **Приём.** Запрос принимает супер-администратор или сотрудник с ролью `regulator`.
   Реквизиты: номер/дата запроса, орган, период, основание.
2. **Исполнение.** Создаётся операция `POST /admin/exports` с полями `legalBasis`,
   `requestRef`, `periodFrom`, `periodTo`, `dateField`, `format`.
3. **Срок.** Целевое время формирования выгрузки за год — не более 30 минут
   при объёме пилотного региона (фиксируется в FZ-NF.5 после нагрузочного прогона).
4. **Формат.** CSV UTF-8 с BOM, разделитель `;`; либо JSON. Контрольная сумма SHA-256
   сохраняется вместе с параметрами запроса.
5. **Фиксация.** Факт предоставления пишется в `regulatory_disclosures` (append-only).
6. **Передача.** Ссылка на файл с TTL 7 суток. Изменение журнала заказов роли
   `regulator` недоступно.
