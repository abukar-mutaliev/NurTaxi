# Обучение операторов: запрос уполномоченного органа (C9.5, FZ-10.6)

Регламент: `docs/compliance/regulatory-request-procedure.md`.

## Кто что делает
1. **Принимает запрос** — региональный администратор или супер-админ. Фиксирует реквизиты (номер, дата, орган, период).
2. **Исполняет выгрузку** — оператор или регуляторская роль в панели: «Выгрузки» → основание, реквизиты, период, поле даты.
3. **Передаёт файл** — скачивает по одноразовой ссылке, сверяет checksum, передаёт по защищённому каналу органа.
4. **Не изменяет журнал** — роль `regulator` не имеет кнопок назначения/возврата.

## Учебный сценарий (стенд)
- Логин `+79000000004` (регулятор), OTP из ответа `/auth/otp/request`.
- Открыть «Заказы», отфильтровать период.
- Создать выгрузку CSV за выбранный месяц.
- Дождаться статуса `ready`, скачать, сверить checksum.
- Открыть «Аудит» — факт чтения и создания выгрузки должен быть в журнале.

Прохождение сценария фиксируется в чек-листе приёмки.
