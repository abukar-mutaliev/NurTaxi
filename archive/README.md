# Архив до редизайна

Файлы, которые редизайн «Слива и пудра» убрал из приложений. Пути внутри папок повторяют
исходные, поэтому любой файл возвращается копированием на прежнее место.

- `old-logo/` — прежний логотип: иконки приложений, splash, favicon, логотип экранов входа,
  favicon панели администратора.
- `old-decor/` — золотые свечения и градиентные фоны экранов.

Новый логотип и скрипты, которые из него собирают все растровые файлы, лежат в `brand/`.
