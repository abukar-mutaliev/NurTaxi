# ADR 0002. Аттестация системы и сертифицированные СЗИ

- **Статус:** Accepted (рабочая гипотеза до закрытия открытого вопроса B.7)
- **Дата:** 2026-08-27
- **Связанные требования:** FZ Приложение B.7, меры C3 и C5

## Контекст
580-ФЗ не формулирует однозначную обязанность аттестации как объекта КИИ.
Решение принимает юридическая служба после классификации системы.

## Решение до закрытия B.7
1. Система **не заявляется** как объект КИИ, пока нет юридического заключения.
2. Меры защиты, эквивалентные аттестации по содержанию, уже в коде: TLS БД/Redis, HSTS, отказ старта без секретов, неизменяемые журналы, шифрование реквизитов разрешений, аудит чтения.
3. После заключения B.7 либо подтверждается этот ADR, либо инициируется аттестация с сертифицированными СЗИ — без переписывания доменной модели.

## Последствия
Регистрация в реестре служб заказа такси не блокируется ожиданием аттестации, если орган не предъявит иное требование.
