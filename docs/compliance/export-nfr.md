# Нефункциональные требования к выгрузке журнала (C4.11, FZ-NF.5)

| Объём | Целевое время генерации CSV | Доказательство |
|-------|-----------------------------|----------------|
| 50 000 заказов (~год при текущем объёме Ингушетии) | ≤ 10 с CPU-сериализации | `export-format.spec.ts` |
| Полный год на staging с реальными строками | ≤ 5 мин wall-clock включая S3 | прогон `POST /admin/exports` на staging |
| Повторная генерация | checksum SHA-256 совпадает | `RegulatoryExport.checksum` |

Нагрузочный прогон на живой БД выполняется на staging после наполнения данными.
Скрипт сериализации вынесен в `server/src/modules/regulatory/export-format.ts`.
